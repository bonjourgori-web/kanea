# Branding KANEA

Le logo principal de KANEA doit etre enregistre ici :

- `kanea_logo.png`

Nom complet :

- **KANEA**
- **Knowledge Anthropology & Neural Engine for Africa**

Usage recommande :

- version principale pour `README`, dashboard Streamlit et presentations
- version compacte ulterieure pour favicon, API docs et icone application

Direction visuelle observee sur le logo fourni :

- arbre symbole d'enracinement, savoir, resilience et Afrique
- cadre fort noir et blanc facile a imprimer
- identite serieuse, scientifique et institutionnelle

Conseil produit :

- conserver ce logo comme identite master
- prevoir plus tard une variante fond transparent pour le dashboard

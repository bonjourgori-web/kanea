KANEA - Breast Cancer AI Detection (Offline AI for Africa)

OBJECTIF :
Creer une application d'intelligence artificielle capable de detecter le cancer du sein a partir d'images de mammographie, fonctionnant en mode local (offline) pour les zones rurales sans Internet.

1. CONTEXTE PROJET

Le cancer du sein est une cause majeure de mortalite chez les femmes africaines. La plupart des cas sont detectes a un stade tardif a cause :
- manque de radiologues
- acces difficile aux centres medicaux
- cout eleve

Le systeme doit :
- detecter precocement les anomalies
- fonctionner sans internet
- aider les agents de sante
